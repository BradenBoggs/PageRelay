# SideWire execution plans

The canonical planning standard, lifecycle rules, and plan register are in [docs/plans/README.md](docs/plans/README.md).

Create or resume living plans in `docs/plans/active/`. Move verified finished plans to `docs/plans/completed/` without creating a second copy. Use the [ExecPlan template](docs/templates/exec-plan.md) only when a plan is needed.

Product sequencing is in [docs/ROADMAP.md](docs/ROADMAP.md); unrelated findings belong in [the technical-debt tracker](docs/plans/tech-debt-tracker.md). This root file is a stable entry point, not a second roadmap or planning standard.
